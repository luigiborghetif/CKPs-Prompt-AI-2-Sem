# Vocabulário local para estimativas de tokens

`cl100k_base.tiktoken` é o arquivo público usado por tiktoken, incluído para
contagem offline. Não representa o tokenizer nativo do Gemma nem cobrança real.

Origem: https://openaipublic.blob.core.windows.net/encodings/cl100k_base.tiktoken
